## Projeto principal em execução

### [Healthcare Interoperability Labs](https://github.com/fernandocerqueira1990-cloud/healthcare-interoperability-labs)

Projeto prático de interoperabilidade em saúde que evoluiu de laboratórios com **Google Cloud Healthcare API** para um **Healthcare Integration Gateway** local, modular e reproduzível.

O MVP atual já implementa e valida:

- ambiente **HAPI FHIR R4 + PostgreSQL**;
- simulador HIS com mensagem **HL7v2 ADT^A01**;
- transporte real via **TCP/MLLP**;
- geração e validação de **ACK AA / AE / AR**;
- **HL7 Parser** e **Validator Core** desacoplados;
- testes automatizados e documentação técnica por milestone.

Próxima evolução: **ADT^A01 → FHIR Patient + Encounter**, seguida por pipeline end-to-end, semantic interoperability, terminology mapping e data quality.

**Stack:** HL7v2, MLLP, FHIR R4, HAPI FHIR, PostgreSQL, Python, Docker, REST APIs, Google Cloud Healthcare API, Pub/Sub, Dataflow, BigQuery, GKE, DICOM/DICOMweb.
